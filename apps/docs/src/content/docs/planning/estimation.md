## Story Point Definition

We use a modified Fibonacci sequence to estimate task complexity and effort.

| Value  | Triviality        | Time Estimate | Examples                                                          |
| :----- | :---------------- | :------------ | :---------------------------------------------------------------- |
| **1**  | Trivial           | 1-2 hours     | Minor UI tweaks, config changes, copy updates.                    |
| **2**  | Very Simple       | 2-4 hours     | Basic CRUD for simple entity, simple validation.                  |
| **3**  | Simple            | 4-8 hours     | Standard CRUD, basic API endpoint, simple component.              |
| **5**  | Medium            | 1-2 days      | Complex form, API with business logic, feature component.         |
| **8**  | Complex           | 3-5 days      | Complete feature module, 3rd party integration, complex workflow. |
| **13** | Very Complex      | 1-2 weeks     | Large feature, complex integration, major refactoring.            |
| **21** | Extremely Complex | 2-4 weeks     | Entire subsystem (e.g., Mobile App), complex integration.         |
| **34** | Epic              | 1-2 months    | Major platform feature, complete redesign.                        |
